## 🛠️ 环境与运行 (Setup)

本项目使用 [uv](https://github.com/astral-sh/uv) 进行高效的 Python 依赖与环境管理。

### 1. 安装环境
确保你已安装 `uv`，然后在根目录下运行：
```bash
uv sync
```

### 2. 运行示例
使用 uv run 执行特定脚本。例如：

```Bash
uv run machine_learning/vae_demo.py
```
